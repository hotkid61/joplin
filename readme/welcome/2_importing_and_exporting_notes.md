# Importing and exporting notes

## Importing from Evernote

Booz Allen Notes can import complete Evernote notebooks, as well as notes, tags, images, attached files and note metadata (such as author, geo-location, etc.) via ENEX files.

To import Evernote data, first export your Evernote notebooks to ENEX files as described [here](https://help.evernote.com/hc/en-us/articles/209005557-How-to-back-up-export-and-restore-import-notes-and-notebooks). Then, on **desktop**, do the following: Open File > Import > ENEX and select your file. The notes will be imported into a new separate notebook. If needed they can then be moved to a different notebook, or the notebook can be renamed, etc. Read [more about Evernote import](https://notes.boozallen.com/help/apps/import_export#importing-from-evernote).

# Importing from other apps

Booz Allen Notes can also import notes from [many other apps](https://notes.boozallen.com/help/apps/import_export#importing-from-other-applications) as well as [from Markdown or text files](https://notes.boozallen.com/help/apps/import_export#importing-from-markdown-files).

# Exporting notes

Booz Allen Notes can export to the JEX format (export archive), which is an archive that can contain multiple notes, notebooks, etc. This is a format mostly designed for backup purposes. You may also export to other formats such as plain Markdown files, to JSON or to PDF. Find out [more about exporting notes](https://notes.boozallen.com/help/apps/import_export#exporting).
